# Scrapper (Godot port)

The native Meta Quest version of Scrapper, being ported from the web version in the repo root.

- Open this folder (`godot/project.godot`) in Godot 4.5.
- Run headless checks: `godot --headless -- --loco-test`

## Ported so far
- Gorilla Tag locomotion (`scripts/gorilla_loco.gd`), same algorithm as the web version
- The lobby room (layout only), XR rig with claws and 45° snap turn
