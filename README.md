# BrowserGtagLocomotion — Backrooms Bot Tag

A WebXR VR game for Meta Quest: tag silly chatbot robots in the Backrooms using Gorilla Tag movement.

**Play:** open https://jonahanoj.github.io/BrowserGtagLocomotion/ in the Quest Browser and press **Enter VR**.

- Push off floors and walls with your hands to move; fling your arms to jump.
- Tap a robot with either hand to tag it.
- Right thumbstick snap-turns. Score and time are on your left wrist.
